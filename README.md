## 💕 Sobre este cantinho

Este é um espaço especial que criei com muito carinho para **guardar os nossos momentos mais preciosos**. Aqui, cada clique é uma memória, cada legenda é um sorriso e cada detalhe foi pensado com todo o meu amor.

É como um álbum de fotos digital, mas com a nossa essência:

- 📸 **Fotos nossas** — dos dias felizes, das risadas, dos abraços.
- 🎵 **Músicas** — aquelas que tocam no fundo e trazem lembranças.
- ✨ **Momentos** — que merecem ser lembrados pra sempre.
